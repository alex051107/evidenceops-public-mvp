# EvidenceOps README illustration prompt

Generated with the built-in Image 2 workflow as a full-width 16:9 GitHub README
hero. The illustration is intentionally separate from the exact SVG technical
workflow.

## Final prompt

```text
Create a publication-quality editorial scientific illustration that makes the
EvidenceOps project understandable at first glance: scientific papers become
exact, auditable evidence rather than generic AI answers.

Use one continuous left-to-right scene on a warm-ivory research desk. Begin
with several distinct scientific papers containing figures, tables, and
paragraph linework. Open one paper and move visually into a specific passage.
Fan many candidate passage strips through a precise evidence-search instrument;
send irrelevant passages to a quiet reject tray while one exact sentence-length
span remains isolated beneath a glass magnifier. End with that span physically
linked to a claim card, citation marker, source identifier, and tamper-evident
audit ledger while a human researcher performs the final inspection.

Use tactile paper, restrained isometric objects, crisp scientific geometry,
transparent glass, brushed aluminum, and subtle brass. Use warm ivory,
graphite, muted teal for verified evidence, amber for exact support, and a
small amount of oxide red for rejected passages. Do not use purple, a
blue-black background, neon, readable prose, a humanoid robot, an AI brain, a
chatbot, cyberpunk effects, glossy SaaS cards, a generic boxes-and-arrows
flowchart, logos, or a watermark.

The route must read as papers -> passages compared -> exact support found ->
human-reviewable evidence record. Keep source identity and citation visibly
attached to the selected span. The final card is a review record, not an
autonomous scientific conclusion.
```
